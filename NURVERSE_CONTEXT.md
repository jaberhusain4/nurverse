## Calculation Architecture

Primary flow:

SettingsProvider
→ MainNavigationScreen/settings synchronization
→ PrayerController
→ PrayerCalculationConfig
→ PrayerEngineService
→ Adhan PrayerTimes
→ Active Home/Prayer UI

Existing calculation settings are persisted through SettingsProvider.

Calculation Method and Madhab changes should trigger prayer-time recalculation.

Do not bypass SettingsProvider with duplicate settings logic.

## Prayer Fixes Already Completed

### Midnight → Fajr Previous Isha

Before:
- After midnight and before Fajr, previous prayer could incorrectly show today's future Isha.

Fixed:
- PrayerController now calculates previous day's Isha using the active calculation configuration.
- Previous prayer time after midnight before Fajr uses yesterday's Isha.

Relevant file:
- lib/controllers/prayer_controller.dart

Do not revert this fix.

## Current Known Prayer Audit Issues

These were identified during a read-only audit.

   - Potential broad widget rebuilds.
   - Must be optimized carefully without breaking live countdown/state.

2. Prohibited/Makruh night-window handling
